# leetcode-pandas

A personal collection of my pandas solutions for the **LeetCode 30 Days of Pandas**
study plan. I started working through these problems back in **2024** when I began
learning pandas, and I keep this repo around as a reference for myself and anyone
else climbing the same learning curve.

## Layout

```
leetcode_pandas/
├── easy/      # 15 short warm-ups (filtering, reshaping, method chaining)
├── medium/    # 15 joins, group-bys, ranks, string/regex tasks
└── hard/      # 6 multi-step problems (top-k, rolling windows, medians)
```

Every file is self-contained: run it directly with `python <file>.py` and the
inline check function will tell you whether the implementation is correct.

## Requirements

- Python 3.10+ (see `pyproject.toml`)
- pandas >= 2.0

## How I use it

- Pick a problem, read the docstring at the top of the file.
- Cover the solution, write my own attempt.
- Run the file — the embedded `_run_checks()` function compares against the
  expected output and prints `✓ <problem-id> test passed` when it matches.

## Notes

Solutions here reflect *my* learning journey — they are not necessarily the
shortest or most idiomatic. I deliberately mix styles across files (method
chaining one day, explicit `.loc` the next, `assign` vs. in-place mutation)
so I get comfortable with the full pandas vocabulary rather than memorising a
single template.

Collected since 2024.
